Payments

  1. Open a Stripe accountAt stripe.com, in the clinic's name, with the bank account the money should land in.
  2. Add STRIPE_SECRET_KEY in VercelProject → Settings → Environment Variables. The value is in Stripe under Developers → API keys. A key starting sk_test_ takes practice payments; sk_live_ takes real ones.
  3. RedeployVercel → Deployments → ⋯ on the latest one → Redeploy. Then refresh this page.

Password

  1. Add ADMIN_PASSWORD in VercelProject → Settings → Environment Variables. At least 10 characters; a few random words work well. It replaces the starter password.
  2. RedeployThen sign in again with the new password.

Good to know

  • Refunds are made in Stripe. Open an order and choose "Open in Stripe".
  • Stripe can email the clinic for every payment and send customers a receipt. Both are switched on in Stripe's settings.
  • Each order's status, note and "sent" time are saved with the payment in Stripe, so nothing is lost if this page is closed.
