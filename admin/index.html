Two settings switch on payments and this page. Add them in Vercel, under the project's Settings → Environment Variables.

  1. ADMIN_PASSWORDThe password for this page. Choose your own, at least 10 characters.
  2. STRIPE_SECRET_KEYFrom Stripe, under Developers → API keys. A key starting sk_test_ takes pretend payments for testing; sk_live_ takes real ones.
  3. RedeployIn Vercel, open Deployments, tap the ⋯ on the latest one and choose Redeploy. Then reload this page.
